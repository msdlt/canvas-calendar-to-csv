Canvas Calendar to CSV

Export dated events from a Canvas course calendar. The tool follows all result pages and downloads a CSV with the event title, description, date, start time, duration, location and address.

Connect to Canvas

Create or copy an API token from the selected instance’s Canvas profile settings. Your token stays in this page’s memory and is cleared when you disconnect or reload.
